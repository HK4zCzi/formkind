# Roadmap

## 0.1 — useful foundation

- Static HTML and URL audits.
- Nine deterministic international-form rules.
- Pretty, JSON, Markdown, and SARIF output.
- Configurable severity and ignore lists.
- Reusable GitHub Action and tested npm package.

## Next

- Vue, JSX, TSX, Svelte, and template-aware parsing without false source locations.
- Browser mode for client-rendered forms.
- Locale profiles for products intentionally limited to specific countries.
- Baseline files so teams can prevent regressions while fixing existing findings.
- Autofix for safe metadata changes such as `lang` and `autocomplete`.
- Community-reviewed references and examples for every rule.
- Telemetry-free VS Code and pre-commit integrations.

Priorities follow demonstrated user needs. The project will not collect audited HTML, personal form submissions, or usage telemetry by default.
