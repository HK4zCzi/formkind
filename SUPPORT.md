# Support

Use GitHub Issues for reproducible bugs and GitHub Discussions for usage questions and ideas. Include the FormKind version, Node.js version, operating system, command, and a minimal HTML sample with personal or secret data removed.

Security issues belong in a private security advisory, as described in [SECURITY.md](SECURITY.md). Conduct reports should follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This volunteer project does not currently offer guaranteed response times or private implementation support.
